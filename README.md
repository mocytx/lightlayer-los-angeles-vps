## 三档线路，贵的钱花在哪

Premium 才是回国线路。官方对这条线的定义包含 CN2、CT、CU、CMI、PCCW、COGENT，中国大陆访问延迟可以做到 50–80ms，跨境连接约 100ms。Global 走国际 BGP，不针对中国大陆做优化，海外访问和 Premium 没差别，国内访问是另一回事。

Standard 夹在中间，官方没有把它标成 CN2 优化，价格却比 Global 贵 $10/年。用户在国内的话，这 $10 花得不明不白，不如直接上 Premium；用户全在海外，Global 就够，没必要为用不上的优化付钱。

## 两个同价位里容易看漏的参数

**端口和流量的组合。** LightLayer 的老款年付方案里，同一个价格出现过「20M 端口不限流量」和「30M 端口带 1TB 月流量」两种版本。选哪个看用途：小站、Bot、监控这类长期低负载选不限流量；跑下载、图床、视频转发放流量上限更划算。端口数字大不等于线路好，这两列要分开看。

**IP 是不是原生。** 洛杉矶各档标注的是原生 IPv4，台湾、香港、新加坡的部分档位是非原生。原生 IP 对解锁流媒体、注册类业务影响很大，广播 IP 在这些场景下容易翻车。
